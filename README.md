## 🚢 Overview

**Vesper Marine Dynamics** is a modern, high-performance web platform representing a world-class autonomous subsea robotics enterprise. The platform showcases uncrewed AUV swarms, hybrid hover ROVs, benthic gliders, and surface satellite gateways operating at depths up to **6,000 meters** (Hadal zone).

The website was designed from the ground up using **Impeccable craft principles**, delivering a distinct visual identity, real physical oceanography equations, and live subsea telemetry simulations without generic AI templates.

## 🎛 Interactive Engineering Modules

- **🌊 Subsea Mission & Acoustic SLAM Simulator (Hero)**: Real-time calculation of hydrostatic pressure (bar/PSI), temperature thermoclines, sound velocity profiles ($v \approx 1449.2 + 4.6T - 0.055T^2 + 0.016D$), round-trip acoustic latency, and interactive sonar wavefront ping triggers.
- **⚡ Modular Payload & Endurance Configurator**: Customise robotic hulls with Synthetic Aperture Sonar (SAS), Subsea Laser LiDAR, automated eDNA samplers, and cathodic protection probes with live power draw, dive endurance, survey range, and downloadable spec sheets.
- **📊 Economic & ESG ROI Forecaster**: Interactive comparison of traditional \$95k/day crewed DP2 vessels against autonomous AUV swarms, forecasting dollar savings (-68%), CO2 reduction (-95%), and eliminated offshore HSE risk hours.
- **🛰 Live Mission Control Hub (`/mission-control`)**: Simulated real-time operations console featuring active swarm telemetry, streaming acoustic mesh terminal logs (AES-256 GCM), and automated AI anomaly classification workflows.
- **📋 Multi-Step Project Scoping Dispatch (`/contact`)**: Enterprise mission request workflow with parameter validation, SLA turnaround commitments, and downloadable proposal receipts.

## 💻 Getting Started

### Prerequisites
- Node.js `v18.0.0+` or `v20.0.0+`
- npm `v9.0.0+` or yarn / pnpm

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/dhanyasreegopinigari-blue/Vesper-Marine-Dynamics.git
   cd Vesper-Marine-Dynamics
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start local development server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

4. **Build for production**:
   ```bash
   npm run build
   ```

5. **Preview production build locally**:
   ```bash
   npm run preview
   ```
